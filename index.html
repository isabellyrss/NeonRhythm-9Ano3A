A Magia do Código!

Como a lógica de programação constrói este jogo em tempo real

Buffer de Antecipação (O Segredo das Setas)

Para as setas começarem do fundo da tela, usamos um Lookahead Buffer de 3 segundos. O código "olha para o futuro" da música e já avisa o sistema gráfico para desenhar a seta bem lá embaixo!

// Olha 3 segundos para o futuro da música
while (nextBeatTime < ctx.currentTime + 3.0) {
spawnSetaParaOFuturo(nextBeatTime);
nextBeatTime += beatInterval;
}

Sintetizador por Código

A música é gerada pela Web Audio API do navegador gerando ondas senoidais e quadradas em tempo real.

const osc = audioCtx.createOscillator();
osc.frequency.setValueAtTime(150, tempoAtual);

Matemática da Colisão

Calculamos a diferença exata de tempo entre a batida alvo da música e o tempo em que você aperta o botão.

let difTempo = Math.abs(nota.hitTime - currentTime);
if (difTempo < 0.05) { retornar "PERFECT!"; }
